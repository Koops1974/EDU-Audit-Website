Common questions

Questions about Cyber Essentials

What is a Cyber Smart reseller?

A certified reseller is authorised to prepare, submit, and support a school's Cyber Essentials assessment on their behalf. EduAudit holds that status, so we handle the whole process for you.

Do we need a full IT audit first?

No — but it helps. If you're starting from scratch we can certify from an assessment alone. If we've already audited your school, we usually have most of the evidence collected.

What if we fail the Plus testing?

We remediate gaps before testing starts so you're in the strongest position to pass first time. If anything surfaces, we fix it and retest.

Is Cyber Essentials compulsory?

Not yet a legal requirement, but it is an increasingly embedded expectation. Many trusts, insurers, and accreditation frameworks reference it, and the DfE has signalled it expects schools to be moving this way.
